# Documentation

Start at the repository [README](../README.md); its table of contents is the
reading order. What lives here:

- `quickstart-claude-code.md` — the tutorial: the compose stack with Claude Code
- `architecture.md`, `what-a-receipt-proves.md`, `deployment-shapes.md`,
  `codex-and-other-clients.md`, `version-pins.md` — explanations
- `policy-from-git.md`, `fold-evidence.md` — how-to guides
- `reference/env.md` — every runtime environment variable
- `auditor/` — offline verification: the walkthrough, `recurse-verify`, the
  bundled-Merkle check and its provenance note
- `developer/` — the contracts and build commands for someone changing the code
- `operator/` — SIEM forwarding through the Vector sidecar
- `release/` — this release's contract, its execution surfaces and evidence
  limits, dependency advisories, storage recovery, and the public-tree policy
