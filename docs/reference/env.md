# Environment variables

Every variable the compose stack reads, with its default and meaning. A value in `.env` takes effect at the next `docker compose up -d`.

## Set in `.env`

`bin/r5e init` creates `.env` from `.env.example`. Compose reads it for `${...}` substitution and passes the whole file to the gateway container.

| Variable | Default | Meaning |
|---|---|---|
| `SECRET_KEY_BASE` | generated by `bin/r5e init` | Encrypts the `r5e_session` cookie. At least 32 characters; the container refuses to start on the placeholder value. |
| `GATEWAY_ADMIN_SESSION_SECRET_KEY_BASE` | generated by `bin/r5e init` | Reserved for a separate admin-session key; nothing in the compose stack reads it today. |
| `POSTGRES_PASSWORD` | `recurse` | Password of the compose-internal Postgres; also embedded in `DATABASE_URL`. |
| `R5E_TENANT_ID` | `01TEN_LOCAL` | Tenant id stamped on every receipt; also the tenant the LLM proxy attributes calls to. |
| `R5E_LOCAL_SIGNING_ALG` | `es256` | Algorithm of the receipt signing key. `es256` is verified by the console and by `recurse-verify`; `ed25519` signs but cannot be verified by either. |
| `R5E_DEV_LOGIN_ENABLED` | `true` | Enables `POST /admin/test/login`, which `bin/r5e login` uses. Set `false` when anyone but you can reach the stack. |
| `R5E_GATEWAY_PORT` | `4000` | Host port of the dashboard and audit API (container port 4000). `bin/r5e` follows it. |
| `R5E_PROXY_PORT` | `4443` | Host port of the LLM proxy listener (container port 4443). What `ANTHROPIC_BASE_URL` points at. |
| `R5E_PUBLIC_HOSTNAME` | `http://localhost:${R5E_GATEWAY_PORT}` | Origin the dashboard is served from. The session JWT issuer and audience derive from it. |
| `R5E_BUILD_CONTEXT` | `.release-context` | Frozen three-repository context generated by `scripts/prepare-release.py`. |
| `R5E_GATEWAY_IMAGE` | `r5e/gateway:local` | Image tag compose runs, and the tag `docker compose build` produces. |
| `LOGGER_LEVEL` | `info` | Gateway log level. `debug` also turns on database query logging, which puts receipt parameters into `docker compose logs`. |
| `R5E_LLM_PROXY_UPSTREAMS` | `anthropic` | Comma-separated upstream presets seeded at boot: `anthropic`, `openai_api`. |
| `R5E_LLM_PROXY_DEFAULT_UPSTREAM_HOST` | `api.anthropic.com` | Where a request whose `Host` header is the gateway itself is sent. `none` leaves only `Host`-header routing. |
| `R5E_LLM_PROXY_FALLBACK_UNKNOWN_HOSTS` | `false` | `true` also sends a request whose `Host` matches no upstream to the default upstream. `false` answers it with `ERR_NO_UPSTREAM_CONFIG`. |
| `R5E_RETAIN_PAYLOADS` | `true` in compose, `false` in the release | Enables the legacy payload mirror. Mandatory admission evidence is retained in the kernel regardless of this flag. |
| `R5E_RETAIN_PAYLOADS_MAX_BYTES` | `8388608` | Per-direction cap. Over it nothing is kept for that direction and the export manifest records `payload_retention: truncated`. |
| `R5E_POLICY_BUNDLE_POLL_MS` | `5000` | Milliseconds between checks of the bundle file's modification time. `0` reloads on SIGHUP only. |
| `R5E_POLICY_GIT_URL` | unset | Git repository the `policy-sync` sidecar (profile `git-policy`) fetches the bundle from. Unset: the gateway serves `./policy/bundle.cedar` from the checkout. |
| `R5E_POLICY_GIT_REF` | `main` | Branch, tag, or full commit sha to follow. |
| `R5E_POLICY_GIT_PATH` | `policy/bundle.cedar` | File in that repository that becomes the bundle. |
| `R5E_POLICY_GIT_INTERVAL` | `30` | Seconds between fetches. |
| `R5E_POLICY_GIT_TOKEN` | unset | Read-only token for a private `https://` repository. Handed to git through a credential helper, never logged. |
| `R5E_POLICY_GIT_USERNAME` | `oauth2` | Username sent with the token. |

## Fixed in `docker-compose.yaml`

Set on the gateway service in `environment:`. Change them by editing the compose file.

| Variable | Value | Meaning |
|---|---|---|
| `R5E_FOLD_ENABLED` | `true` | Required. Unset means enabled; any value other than `true` (any case) refuses startup, so a mistyped `0`/`no`/`off` is refused rather than silently ignored. |
| `R5E_FOLD_DATA_DIR` | `/data/kernel` | Durable kernel log, CAS, and keys. |
| `R5E_FOLD_START_SERVER` | `false` | Keep the kernel standalone HTTP listener unbound. |
| `R5E_START_HTTP` | `true` | Start the audit-plane listener (dashboard and API). |
| `PORT` | `4000` | Container port of the audit plane. |
| `R5E_AUDIT_CONSOLE_ENABLED` | `true` | Serve the dashboard under `/admin`. |
| `R5E_BROKER_MODE` | `collapsed` | The identity broker runs inside the gateway process; there is no broker container. |
| `BROWSER_OIDC_PROVIDER` | `oidc` | Browser sign-in provider family. No issuer is configured; the dev login stands in for it. |
| `R5E_SECURE_COOKIE` | `false` | Session cookie without the `Secure` flag, for plain `http://localhost`. Only the literals `true` and `false` are accepted. |
| `BROKER_JWT_SIGNING_KEY_PATH` | `/secrets/broker-signing-key.pem` | ES256 key that signs browser-session JWTs. Generated on first boot into the `secrets` volume. |
| `R5E_LLM_PROXY_ENABLED` | `true` | Start the LLM proxy listener. |
| `R5E_LLM_PROXY_SCHEME` | `http` | Scheme of the proxy listener. |
| `R5E_LLM_PROXY_PORT` | `4443` | Container port of the proxy listener. |
| `R5E_LLM_PROXY_DEFAULT_TENANT_ID` | `${R5E_TENANT_ID}` | Tenant the proxy attributes calls to. |
| `R5E_PROVIDER_LEDGER_IMPL` | `postgres_merkle` | Ledger provider: Postgres rows plus Merkle roots. |
| `R5E_PROVIDER_PAYLOAD_BROKER_IMPL` | `filesystem` | Payload store provider. |
| `R5E_CAS_ROOT` | `/data/cas` | Root of the content-addressed payload store (`cas` volume). |
| `R5E_PROVIDER_SECRETS_IMPL` | `local_pem` | Receipt signer provider: a PEM key on disk. |
| `R5E_LOCAL_SIGNING_KEY_PATH` | `/secrets/local-signing-key.pem` | Receipt signing key. Generated on first boot into the `secrets` volume. |
| `R5E_PROVIDER_POLICY_IMPL` | `filesystem` | Policy provider: one Cedar file. |
| `RECURSE_POLICY_BUNDLE_PATH` | `/policy/bundle.cedar` | The one Cedar file the gateway evaluates (`policy` volume). |
| `RECURSE_POLICY_SCHEMA_PATH` | set in the image | Cedar entity schema, baked into the image by the Dockerfile. |
| `DATABASE_URL` | `postgres://recurse:${POSTGRES_PASSWORD}@postgres:5432/recurse` | The compose-internal Postgres. |
| `R5E_DATABASE_SSL` | `false` | No TLS to the compose Postgres. Only the literals `true` and `false` are accepted. |

## Read by `bin/r5e`

| Variable | Default | Meaning |
|---|---|---|
| `R5E_GATEWAY_PORT` | value in `.env`, else `4000` | Port used for every request the script makes. |
| `R5E_GATEWAY_URL` | `http://localhost:${R5E_GATEWAY_PORT}` | Overrides the whole base URL. |
| `R5E_PROXY_PORT` | `4443` | Port printed by `bin/r5e claude-code setup`. |
| `R5E_STATE_DIR` | `.r5e` in the checkout | Where the script keeps its cookie jar and the evidence exports. |
| `R5E_FOLD_PROJECT` | `r5e` | Compose project name the `--fold` export and verify commands look for the gateway container under. |
